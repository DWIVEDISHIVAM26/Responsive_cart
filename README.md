Responsive Cart Page:

A responsive and functional shopping cart webpage built with HTML, CSS, and JavaScript. This project includes dynamic cart functionality, such as updating quantities, recalculating totals, and removing items, making it a great example of modern web development techniques.

Features:

Dynamic Cart Updates:

Automatically recalculates subtotal and total prices based on item quantities.
Allows users to update quantities directly from the cart.

Item Removal:

Users can remove individual items using a trash icon.
Subtotals and totals update dynamically upon item removal.

Responsive Design:

Optimized for different screen sizes using modern CSS techniques.

Interactive UI:

Uses JavaScript for real-time cart updates and user interactions.

Technologies Used:

HTML: For structuring the content.
CSS: For responsive styling and layout.
JavaScript: For dynamic interactivity.

How to Use:

Add Items to Cart:

Items are preloaded in the cart for demonstration purposes.

Update Quantities:

Use the quantity input fields to change the quantity of items in the cart.
Totals will update automatically.

Remove Items:

Click the trash icon next to an item to remove it from the cart.
The cart totals will recalculate after removal.

Checkout:

Click the "Check Out" button to simulate the checkout process.
